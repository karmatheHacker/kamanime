# 🌸 Zenshin - Premium Anime Experience

Zenshin is a high-performance anime tracking and streaming application designed to bridge the gap between tracking platforms like **AniList** and various streaming sources.

## 📂 Repository Structure

- [**web-version/**](./web-version): The modern web implementation of Zenshin. It utilizes a hybrid architecture with a local Node.js bridge to provide desktop-grade features in a browser environment.
- [**original-repo/**](https://github.com/hitarth-gg/zenshin): Link to the original Electron-based desktop application.

## 🚀 Getting Started with the Web Version

The web version is located in the `web-version` directory. It consists of a React frontend and a Node.js backend server that handles torrent streaming and scraping.

For detailed technical information on how the web version operates, please refer to:
👉 **[Web Version Documentation](./web-version/README.md)**

## 🌟 Key Features

- **AniList Integration**: Sync your watch status, scores, and lists automatically.
- **High-Quality Streaming**: Powered by WebTorrent for fast, peer-to-peer playback.
- **Smart Scraping**: Integrated support for AnimePahe and other providers.
- **Real-time Syncing**: State persistence across devices via Convex.
